# スタイルガイド（career テーマ）

正本は `slides/themes/career.css`。ここはその使い方と、文章側のルール。CSS を変えたらここも合わせる。

## デザイン哲学

1. **シンプル。** 情報を詰め込まない。1枚1メッセージ
2. **色は少なく。** 紺（primary）とグレーが基調。アクセントは限定的に
3. **読みやすさ優先。** 文字サイズと余白はテーマに任せ、スライド側で上書きしない
4. **一貫性。** 同じ種類の内容には同じ型を使う

## 色

| 変数 | 色 | 用途 |
|---|---|---|
| `--primary` | `#1b3a5c` 紺 | 見出し、`**強調**`、表ヘッダー、lead 背景 |
| `--accent` | `#e8871e` オレンジ | `*強調*`（em）。**1枚に1か所まで** |
| `--accent-sub` | `#2f7f9d` 青緑 | 小見出し（h6）、リストマーカー、cards の上線 |
| `--text` / `--text-sub` | 本文 / 補足 | 補足はグレーで一段下げる |
| `--bg-sub` / `--line` | 薄い背景 / 罫線 | パネル・区切り |

- 影・グラデーションは使わない。重要度は文字の大きさと太さで表す
- 赤・緑などの原色で強調しない。`style="color:..."` を書かない
- `*em*` は本当に大事な1語だけ。迷ったら `**strong**`（紺）にする

## 文字と分量

| 項目 | 発表用 | 配布用（handout） |
|---|---|---|
| 1枚の主張 | 1つ | 1つ（説明を足してよい） |
| 箇条書き | 3〜4項目、1項目1行 | 5項目まで、2行まで |
| message の見出し | 2行まで | 2行まで |
| 縦に並べる項目 | 4つまで | 5つまで |

- タイトル（h2）は「トピック名」でもよいが、message 型の h1 は**主張の文**にする（例: ×「課題」→ ○「レビュー待ちが開発を遅くしている」）
- 感嘆符（！）、装飾目的の絵文字は使わない
- 疑問文は「問いかけ」の枚だけにする
- コロン（：）は「上期：基盤を作る」のようなラベル用途ならよい

## 構成

- 同じ型を3枚続けない
- 表紙と章の区切りは lead
- 最後は「次にやること」か「お願い」で終える
- 中身はユーザー本人の言葉・材料から取る。Claude が補った言い回しは報告時に明示する

## 崩れの定石

| 症状 | 原因 | 直し方（上から順に試す） |
|---|---|---|
| 下端がはみ出す・ページ番号と重なる | 項目が多い／文が長い | ① 文を短くする ② 項目を減らす ③ 2枚に分ける ④ 配布用なら handout |
| 縦に5項目以上で入らない | 1列に詰めすぎ | cards（`--cols` 2 や 3）で横に並べる。それでも多ければ分割 |
| steps のカードの高さがバラバラ | 説明文の長さが不揃い | 各ステップの説明を同じくらいの長さ（1行）に揃える |
| cards の中で折り返しが汚い | 列数に対して文が長い | 列数を減らす（five → 3列 → two） |
| 空きすぎて寂しい | 内容が薄い | 型を message に変えて1メッセージを大きく見せる |

- 余白を詰めるために `style` で margin/padding を上書きしない。内容を減らすのが先
- 文字サイズを下げたいときは handout クラスを使う（個別に font-size を書かない）
